# enclosure

CAD design for the physical housing that protects the sensor node board in the field (e.g.
mounted on or near an irrigation pipe), plus the antenna mount for the LoRa radio.

Put CAD source files (e.g. `.f3d`, `.step`) and exported print/manufacturing files (`.stl`) here.
These are binary and tracked with git-lfs — see the root `.gitattributes`.

This needs to match the physical dimensions of whatever board comes out of `hardware/circuit/`,
and needs antenna clearance appropriate for the LoRa module used there.
